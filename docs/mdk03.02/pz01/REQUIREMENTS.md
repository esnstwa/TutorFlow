# Спецификация требований TutorFlow 1.0

**Версия:** 1.0
**Основание:** аудит репозитория и исходное задание ПЗ №1; интервью с заказчиком отсутствует.
**Статусы:** `implemented` — подтверждено кодом и тестами; `partial` — часть поведения есть, эксплуатационные элементы отсутствуют; `planned` — кода нет.

## Назначение и границы

Система обеспечивает сквозное взаимодействие частного преподавателя и ученика: идентификация, явная привязка, выдача задания, сдача, проверка и история. В версию 1.0 не входят оценки, группы, автоматическая почта, recovery, фоновые задачи и реальная синхронизация Google Calendar.

## Пользователи и основной сценарий

- Преподаватель управляет только собственными карточками учеников, занятиями и заданиями.
- Ученик видит только назначения связанного профиля и отправляет собственные решения.
- Основной сценарий описан в [MVP.md](MVP.md).

## Существенные ошибочные сценарии

- неверный пароль/истёкшая сессия; отсутствующий или неверный CSRF;
- приглашение просрочено, отозвано, использовано, email не совпадает, конкурентное принятие;
- чужой или архивный ученик в назначении;
- пустое домашнее задание/отправка, чужой файл, повторная сдача до review;
- проверка неотправленной или чужой работы;
- некорректный интервал/статус занятия;
- недоступна БД или файловая система, миграция не применена.

## Ограничения, допущения и открытые вопросы

## Исходное состояние для проверки

1. Python 3.12 и зависимости `.[dev]`; Node.js 20+ для JS-тестов.
2. Для unit/integration: `TMPDIR` указывает на существующий temp-каталог в Windows; pytest создаёт отдельные БД.
3. Для миграций: пустая PostgreSQL 16 и `DATABASE_URL`; `APP_ENV=test`.
4. Команды: `python -m compileall -q app`, `python -m pytest -q`, Node-команды из README, `python -m alembic upgrade head`, `python -m alembic check`.

## Ранние риски безопасности

- неограниченный размер/тип загрузки и отсутствие антивирусной проверки;
- локальные uploads без production volume/backup;
- отсутствие recovery/email verification и rate limiting входа;
- XSS-риск при будущих изменениях шаблонов/JS с пользовательским содержимым;
- утечка invitation URL получателем ссылки до использования;
- отсутствие формализованного retention/удаления персональных данных.

Связанные меры и будущие проверки приведены в [SECURITY_BASELINE.md](SECURITY_BASELINE.md).
