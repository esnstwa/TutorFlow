# Definition of Done

Изменение считается Done только если выполнены все применимые пункты.

- [ ] Назначение и пользовательская/инженерная ценность понятны из issue и PR.
- [ ] Границы изменения не содержат несвязанных правок.
- [ ] Критерии приёмки и существенные ошибочные исходы проверены.
- [ ] Наблюдаемое поведение воспроизводимо командой, тестом или описанным сценарием.
- [ ] Все применимые локальные проверки и CI прошли; пропуск объяснён в PR.
- [ ] Миграции имеют один head, применяются на чистой БД; влияние на данные и rollback описаны.
- [ ] Документация, требования и `.env.example` обновлены при изменении контракта/config.
- [ ] В diff нет секретов, `.env`, БД, uploads, персональных файлов и отладочного мусора.
- [ ] Проверены роль, владение объектом, невалидный ввод и отказ внешнего ресурса.
- [ ] Значимое изменение получило независимый approval (не от автора).
- [ ] Все review comments разрешены; решения не скрыты устной договорённостью.
- [ ] PR связан с issue, CI зелёный, ветка актуальна относительно `main`.
- [ ] После merge карточка доказательств содержит фактические commit/PR/run; tag создан только при готовности сдачи.

Для текущей ПЗ пункты интервью, независимого оппонирования и `TODO(student)` являются условиями полной учебной сдачи, а не могут быть отмечены выполненными автором кода.
