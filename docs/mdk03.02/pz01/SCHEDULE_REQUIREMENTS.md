Числовое условие NFR-02 — **0 изменённых строк занятий и HTTP 403 при каждой отклонённой пробе**. Изменение с корректным токеном остаётся подчинено правилам роли, владения и предметной валидации. Исключения для входа и регистрации описаны в общей спецификации. Отсутствие Origin само по себе не отключает проверку токена.

Для учебного минимума расписания достаточно создания разового занятия и повторного просмотра. Перенос, правка и отмена существуют и проверяются по применимым ограничениям доступа. Уточнение не утверждает новые правила пересечений, касания границ, переходов статусов и конкурентной записи. Владелец подтвердил политику временных конфликтов для отдельного изменения. См. [проект CR-001](CR001_SCHEDULE_CONFLICTS.md). Повторяющиеся занятия не входят в подтверждённый объём.
