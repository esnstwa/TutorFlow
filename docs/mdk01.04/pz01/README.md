## Техническая часть

Самостоятельный вклад для зоны расписания — включение шаблона `app/web/templates/pages/schedule.html` и CSS `app/web/static/css/schedule.css` в wheel с проверкой состава пакета. Общая часть каркаса — безопасные сведения о приложении/окружении/версии/Git SHA, события запуска и завершения, расширение `/health`, проверка валидной/невалидной конфигурации и содержательная проверка SHA в Quality Gate. Бизнес-логика расписания, авторизация и UI не менялись.
