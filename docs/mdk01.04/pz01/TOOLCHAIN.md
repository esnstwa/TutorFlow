## Ограничения контура

- `uv.lock` фиксирует версии пакетов и контрольные хэши; `requires-python` в `pyproject.toml` задаёт Python `>=3.12`. Docker и GitHub Actions выбирают ветку 3.12; полный локальный patch-релиз следует записывать из `python --version` в протоколе.
- CI проверяет синтаксис, тесты, миграции и конкретный минимальный компонент. Он не заменяет независимую проверку другим студентом, браузерную проверку всех экранов или ручную проверку production-инфраструктуры.
- Профилирование — учебная демонстрация инструмента, не доказательство, что одна сборка быстрее другой.
- Не подключённые Redis, Celery, отдельный типовой анализатор и отдельная система мониторинга не объявляются работающими средствами.
